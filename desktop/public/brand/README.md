# OpenDrobo visual assets

`opendrobo-lineup-v2.png` and the icon master at `desktop/src-tauri/icons/source-v2.png` are newly AI-rendered OpenDrobo artwork. They use a recognizable five-bay direct-attached storage enclosure as a hardware reference, while adding the OpenDrobo identity and independently rendered lighting.

The lineup is a decorative background only. Its green bay lights and blue lower windows do not represent connected-device telemetry. Live enclosure LEDs in the application are code-rendered from current decoded status data.

These assets do not establish trademark or redistribution clearance, and do not change the supported-device or service boundaries documented elsewhere in the project.

The icon master is kept outside the web public directory; only the decorative lineup is embedded in the dashboard frontend. Platform icons were generated from that master with the pinned Tauri CLI.
