# Application screenshots

Captured November 6, 2026 from the current OpenDrobo 0.2.0 Intel preview, built from application source at `ad7599d21ce7957ce26fa2a5ffdbd1380e10b532`. The connected unit is a Drobo 5D over Thunderbolt on macOS 14.7.7, using the original Drobo driver and service. This is one observed configuration, not certification of other models, Apple-silicon connectivity or a replacement driver.

The images were captured on the local Mac from its Screen Sharing window after navigating the home-Mac application through Computer Use. Each image contains only the observed 1120 × 800 app window. Framing removes surrounding desktop and Screen Sharing chrome. Standard sRGB conversion replaces the local display profile; no interface content or displayed value was changed. No generated interface, replacement values or simulated fault state was inserted. A rejected local region capture and complete window captures remain private and are not part of this gallery.
